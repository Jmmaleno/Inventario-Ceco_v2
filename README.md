# Recuento Inventario Android 14

- Flujo automatico: Zona -> Numero inventario -> Etiqueta -> Kilos -> guardar -> Numero inventario.
- Foco automatico en el campo activo.
- Teclado numerico para inventario y kilos; sin ejemplos en los campos.
- Etiqueta completa en una sola celda Excel.
- Registros guardados visibles permanentemente en la mitad inferior.
- Papelera individual con confirmacion de borrado.
- SQLite para continuar recuentos.
- Excel guardado en Descargas con zona, fecha y hora.
- GitHub Actions compila app-release.apk.
